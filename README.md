# Titanic Survival Analysis

A Jupyter Notebook project exploring passenger survival in the Titanic training dataset.

## Project structure
- `Src/` – notebook and Python source code.
- `Data/` – input dataset (`train.csv`).
- `Docs/` – written summary of findings.
- `Results/` – survival visualizations.
## Questions explored
1. How does survival differ by sex?
2. How does survival differ by passenger class?
3. How does survival differ across age groups?

See `Docs/Summary_of_Findings.md` for the findings.
