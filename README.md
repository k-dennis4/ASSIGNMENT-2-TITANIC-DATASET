# Titanic Survival Analysis

A Python/Jupyter Notebook project exploring passenger survival in the Titanic training dataset.

## Project structure
- `Src/` – notebook and Python source code.
- `Data/` – input dataset (`train.csv`).
- `Docs/` – written summary of findings.
- `Results/` – survival visualizations.

## Run the analysis
Install dependencies with `pip install -r requirements.txt`. Open `Src/Titanic_Survival_Analysis.ipynb` in Jupyter. The notebook reads `Data/train.csv` using a relative path and saves charts to `Results/`.

## Questions explored
1. How does survival differ by sex?
2. How does survival differ by passenger class?
3. How does survival differ across age groups?

See `Docs/Summary_of_Findings.md` for the findings.
